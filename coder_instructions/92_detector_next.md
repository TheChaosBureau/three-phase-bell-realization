### 2. Promote “race-law fidelity” to the main KPI

Do not optimize primarily for (\lambda(P)) linearity.

Optimize for:
[
P(\text{branch 1 wins}) \approx \frac{P_1}{P_1+P_2}.
]

A detector can look great in single-branch calibration and still fail as a competing detector.

So your ranking should weight:

* race RMS error first
* linearity second
* dark counts third
* robustness fourth

### 3. Find the viable operating window, not just one good point

For the winning model, characterize the **region** in parameter space where it works.

That means making 2D slices like:

* `eps_event` vs `p_trig`
* `lambda_dark` vs `dead_time`
* `bias` vs `noise`
* `threshold` vs `sigma`

You want to know whether the detector law is:

* structurally robust
* or fine-tuned

That will decide whether this is worth porting to SPICE/hardware.

### 4. Add a “first-click vs accumulation” discriminator plot

You already learned this conceptually. Now encode it numerically.

For each model, produce:

* waiting-time histogram
* coefficient of variation
* race-law error
* branch asymmetry amplification

This will make the contrast obvious:

* first-event models preserve Born-like weights
* accumulators distort them

That becomes a core figure for your notes.

### 5. Build the two-branch integration surrogate

Once `shot_trigger` looks good, stop treating powers (P_1,P_2) as arbitrary numbers.

Drive the detector search harness from the **actual branch weights** generated by your reduced front-end:
[
P_1 \propto w_1,\qquad P_2 \propto w_2.
]

So the integration test becomes:

* prepare state (a)
* choose analyzer angle (\theta)
* compute (w_1,w_2)
* feed detector model with corresponding branch powers
* verify winner frequency (\approx w_1,w_2)

That is the real single-particle closure of the whole story.

### 6. Then lift to the 4-branch joint case

Only after the 2-branch chain is solid, do the 4-branch extension.

Same detector model, but now with:
[
P_{xy}\propto w_{xy}(a,b)
]
for the four joint branches.

Then check:

* sampled joint outcomes match (w_{xy})
* correlator matches the reduced model
* CHSH survives the detector layer

This is the actual bridge from reduced shared-state math to detector-mediated joint outcomes.

### 7. Write the detector theorem as an engineering result

Once `shot_trigger` wins, write a short note with the actual claim:

> In the rare-event regime, a detector whose micro-absorption opportunities arrive at rate proportional to absorbed branch power and whose per-opportunity trigger probability is approximately constant yields a first-click hazard (\lambda(P)\approx \alpha P). Combined with linear analyzer branch intensities, this produces Born-like winner frequencies.

That becomes the detector-layer foundation for the project.
