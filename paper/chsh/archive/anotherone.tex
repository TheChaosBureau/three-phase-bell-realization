\section{Analytic Phase Diagram for Threshold and Coincidence Detection}

\subsection{Overview}

We extend the threshold-only detection model to include finite coincidence windowing, while retaining square-law energy extraction and fixed energy thresholds. The resulting model remains local and energy-conserving but introduces physically motivated selection via threshold crossing and coincidence timing.

We derive an analytic surrogate for the CHSH parameter $S$ as a function of:

\begin{itemize}
    \item normalized threshold $t = \eta/E_0$,
    \item coincidence window $\Delta$,
    \item pulse width $\sigma$.
\end{itemize}

This produces a closed-form phase diagram describing the tradeoff between CHSH violation and coincidence efficiency.

\subsection{Threshold Half-Width}

Let
\begin{equation}
a(t) = \arccos(\sqrt{t}),
\qquad
b(t) = \arcsin(\sqrt{t}) = \frac{\pi}{2} - a(t).
\end{equation}

Define the threshold acceptance half-width
\begin{equation}
\boxed{
m_{\mathrm{thr}}(t) = \min\{a(t), b(t)\} \in [0,\pi/4].
}
\end{equation}

The single-detector click efficiency is
\begin{equation}
\boxed{
\varepsilon_{\mathrm{single}}(t) = \frac{4 m_{\mathrm{thr}}(t)}{\pi}.
}
\end{equation}

At $t=1/2$, $m_{\mathrm{thr}}=\pi/4$ and $\varepsilon_{\mathrm{single}}=1$ (no discards). As $t \to 0$ or $t \to 1$, $m_{\mathrm{thr}} \to 0$ and efficiency vanishes.

\subsection{Coincidence Window as an Effective Angular Filter}

Let the channel energy projection be
\begin{equation}
u = \cos^2(\phi-\theta).
\end{equation}

For a Gaussian pulse envelope, the click time is
\begin{equation}
t_c(u) = \sigma\, \mathrm{erf}^{-1}\!\left(\frac{\beta}{u} - 1\right),
\end{equation}
with $\beta$ determined by threshold and detector gain.

A coincidence window $|t_A - t_B| \le \Delta$ implies approximately
\begin{equation}
|u_A - u_B| \le \delta u,
\end{equation}
where
\begin{equation}
\boxed{
\delta u(\Delta) = \frac{\Delta}{|t_c'(u_*)|}
}
\end{equation}
for representative $u_*$ in the accepted ensemble.

Using
\begin{equation}
u_A - u_B = -\sin(2(\phi - m)) \sin(\Delta\theta),
\end{equation}
with $m = (\theta_A+\theta_B)/2$, the coincidence condition becomes
\begin{equation}
|\sin(2(\phi - m))| \le r,
\qquad
r = \frac{\delta u}{|\sin(\Delta\theta)|}.
\end{equation}

This defines coincidence acceptance lobes with effective half-width
\begin{equation}
\boxed{
m_{\mathrm{coin}}(\Delta\theta;\Delta)
=
\frac{1}{2}
\arcsin\!\left(
\min\left\{1,\frac{\delta u(\Delta)}{|\sin(\Delta\theta)|}\right\}
\right).
}
\end{equation}

\subsection{Effective Half-Width and Correlation Surrogate}

The surviving ensemble is governed by the tighter of threshold and coincidence filters:
\begin{equation}
\boxed{
m_{\mathrm{eff}}(\Delta\theta; t,\Delta)
=
\min\big(
m_{\mathrm{thr}}(t),
m_{\mathrm{coin}}(\Delta\theta;\Delta)
\big).
}
\end{equation}

The conditioned correlation is approximated by the threshold-only overlap formula evaluated at $m_{\mathrm{eff}}$:
\begin{equation}
\boxed{
\mathcal{E}(\Delta\theta; t,\Delta)
\approx
\mathcal{E}_{m_{\mathrm{eff}}}(\Delta\theta),
}
\end{equation}
where
\begin{equation}
\mathcal{E}_{m}(\Delta)
=
\frac{
[2m-|\Delta|]_+
-
[2m-(\frac{\pi}{2}-|\Delta|)]_+
}{
[2m-|\Delta|]_+
+
[2m-(\frac{\pi}{2}-|\Delta|)]_+
}.
\end{equation}

\subsection{CHSH Parameter}

For standard CHSH angles,
\begin{equation}
\theta_A \in \{0,\pi/4\},
\qquad
\theta_B \in \{\pi/8, 3\pi/8\},
\end{equation}
the CHSH parameter becomes
\begin{equation}
\boxed{
S(t,\Delta)
\approx
\left|
3\mathcal{E}(\pi/8; t,\Delta)
-
\mathcal{E}(3\pi/8; t,\Delta)
\right|.
}
\end{equation}

\subsection{Coincidence Efficiency}

An approximate coincidence efficiency for a setting pair is
\begin{equation}
\boxed{
\eta_{\mathrm{coin}}(\Delta\theta; t,\Delta)
\approx
\frac{4}{\pi} m_{\mathrm{eff}}(\Delta\theta; t,\Delta).
}
\end{equation}

For CHSH experiments, define
\begin{equation}
\boxed{
\eta_{\mathrm{coin}}^{\mathrm{(CHSH)}}(t,\Delta)
=
\min\{
\eta_{\mathrm{coin}}(\pi/8; t,\Delta),
\eta_{\mathrm{coin}}(3\pi/8; t,\Delta)
\}.
}
\end{equation}

\subsection{Phase Diagram: Tradeoff Between $S$ and Coincidence Efficiency}

\paragraph{Proposition (Detection-Induced Violation Tradeoff).}
Under square-law detection with fixed threshold and finite coincidence window:

\begin{enumerate}
    \item If $m_{\mathrm{eff}}(\Delta\theta)=\pi/4$ for all relevant $\Delta\theta$, then
    \[
    S = 2.
    \]
    \item As $m_{\mathrm{eff}}$ decreases due to thresholding and/or tightening coincidence window, $S$ increases continuously.
    \item In the limit $m_{\mathrm{eff}}\to 0$ (vanishing coincidence efficiency),
    \[
    S \to 4.
    \]
\end{enumerate}

Moreover,
\begin{equation}
\boxed{
S \text{ increases monotonically as }
\eta_{\mathrm{coin}}^{\mathrm{(CHSH)}} \text{ decreases}.
}
\end{equation}

Thus any apparent violation $S>2$ is accompanied by reduced coincidence efficiency.

\subsection{Interpretation}

This phase diagram makes explicit the classical detection-loophole tradeoff:

\begin{itemize}
    \item At full efficiency ($\eta_{\mathrm{coin}}=1$), $S=2$.
    \item Moderate thresholding and coincidence filtering can produce $2 < S < 4$.
    \item Extreme filtering drives $S\to 4$ while $\eta_{\mathrm{coin}}\to 0$.
\end{itemize}

The curvature necessary to exceed the Bell bound arises entirely from selective retention of events determined by physically motivated detection nonlinearities.

No nonlocal dynamics are introduced; the violation emerges from conditioning on detection events.
